Core Pillars

Security Fundamentals

Confidentiality
Integrity
Availability
01. Confidentiality +
Ensuring that sensitive information is accessible only to authorized individuals and protected from disclosure.
02. Integrity +
Maintaining the accuracy, completeness, and uncorrupted state of data across storage and transmission.
03. Availability +
Ensuring that systems, networks, and applications remain operational and accessible when required by authorized users.
04. Authentication +
Verifying the identity of a user, system, or application before granting digital access.
05. Authorization +
Determining specific access rights, permissions, and privileges for authenticated entities.
06. Encryption +
Encoding plain data into ciphertext using cryptographic algorithms to ensure private transmission.
